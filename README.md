# SYNAPSE Robotics — Website Concept

Багатосторінковий концепт сайту вигаданої робототехнічної компанії SYNAPSE Robotics.

## Запуск

Розпакуйте архів та відкрийте `index.html` у браузері. Усі сторінки, зображення, CSS і JavaScript знаходяться всередині проєкту, а всі посилання відносні. Для локальної розробки з автоматичним оновленням можна використати VS Code + Live Server.

## Структура

- `index.html` — головна сторінка, Hero N1, серія роботів, технології, рішення, дослідження, новини, про компанію, контакти.
- `pages/robots.html` — каталог роботів.
- `pages/robot-n1.html` — модель N1.
- `pages/robot-a7.html` — модель A7.
- `pages/robot-m3.html` — модель M3.
- `pages/technology.html` — технології AI Core / Vision / Motion.
- `pages/solutions.html` — галузеві сценарії.
- `pages/research.html` — дослідження.
- `pages/news.html` — публікації з фільтрами.
- `pages/about.html` — концепція компанії.
- `pages/contact.html` — інтерактивне формування тексту звернення.
- `assets/css/style.css` — адаптивна дизайн-система й анімації.
- `assets/js/main.js` — навігація, скрол-анімації, паралакс, фільтри й форма.
- `assets/images/` — локальні WebP-зображення.
